# Elektro Hero Plugin

The Elektro Hero Plugin is a WordPress Gutenberg plugin that provides a customizable hero component for your website. This component allows users to edit text inline and customize the background image using the WordPress media library.

## Features

- Inline text editing for the hero component.
- Background image customization through the WordPress media library.
- Responsive design that looks great on all devices.
- Easy to use with the Gutenberg editor.

## Installation

1. Download the plugin files.
2. Upload the `elektro-hero-plugin` folder to the `/wp-content/plugins/` directory.
3. Activate the plugin through the 'Plugins' menu in WordPress.
4. Add the hero block to your posts or pages using the Gutenberg editor.

## Usage

- Once activated, you can add the hero block to any post or page.
- Click on the block to edit the text inline.
- Use the media library to select or upload a background image for the hero component.
- Customize the styles as needed using the provided CSS files.

## Development

To contribute to the development of this plugin, you can clone the repository and run the following commands:

```bash
npm install
npm run build
```

This will install the necessary dependencies and build the plugin assets.

## Localization

The plugin is ready for translation. You can find the translation template in the `languages` folder.
